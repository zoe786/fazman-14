# Smile Marketplace

A minimal full-stack starter for a dental marketplace like Airbnb.

## Stack

- **Frontend:** React with Next.js (`/tmp/workspace/zoe786/fazman-14/apps/web`)
- **Backend:** Node.js with Express (`/tmp/workspace/zoe786/fazman-14/apps/api`)
- **Database target:** PostgreSQL
- **Media storage target:** Private VPS-hosted storage

## Scripts

From `/tmp/workspace/zoe786/fazman-14`:

- `npm run lint` — lint the Next.js frontend
- `npm run build` — build the Next.js frontend
- `npm run test` — run the API tests

## Current implementation

- Shared platform blueprint covering roles, discovery, booking, operations, procedures, and compliance
- Next.js landing page that renders the dental marketplace architecture
- Express API endpoints for health, platform blueprint, procedures, and security posture
